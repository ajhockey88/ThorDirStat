📦 See what apps take up, and select whole folders in the treemap.

## ✨ What's new
- 📦 **`<Apps>`:** the space installed apps and their data take is no longer hidden in `<Unknown>`. Internal storage now has an `<Apps>` folder with each app's size. Hold an app for **App info**, to clear its cache or uninstall it. `<Unknown>` now covers only what's left, mostly Android itself.
  - With Shizuku allowed, this switches on by itself. Otherwise, tap **Allow usage access** in 💽 Drives.
- ☝️ **Tap a rectangle again** in the treemap to select the folder around it. Keep tapping to climb up a level each time, so you can see which folder a block of tiny files belongs to.
- ⬆️ **Parent folder** button at the bottom left of Folders selects the folder that holds the selected item.

## 📲 Install
Tap **Check for updates** at the bottom of Settings, or download `ThorDirStat.apk` below and install it over the old one. Then scan again to see `<Apps>`.
