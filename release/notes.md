🗑️ Deleting game and app data in Android/data and Android/obb now works.

## ✨ What's new
- 🗑️ **Deleting an app's folder in Android/data or Android/obb** (for example `com.albiononline`) no longer says "Couldn't delete". Android doesn't let anyone remove those folders themselves, so ThorDirStat deletes everything inside, frees the space, and leaves the empty folder.
- The folder then shows as 0 bytes, and the message says it was emptied.

## 📲 Install
Tap **Check for updates** at the bottom of Settings, or download `ThorDirStat.apk` below and install it over the old one.
