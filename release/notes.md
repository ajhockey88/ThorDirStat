🗺️ The treemap now shows only space that's in use.

## ✨ What's new
- 🧹 **No more `<Free space>` in the treemap:** a drive's free space was drawn as a big grey block that was easy to mistake for a large file. The treemap and folder list now show only files, folders and `<Unknown>`, as WinDirStat does by default.
- 💽 Each drive's free space is still shown in **Drives**, with its used / free bar.
- ⚙️ The **Show `<Free space>`** setting has been removed.

## 📲 Install
Tap **Check for updates** at the bottom of Settings, or download `ThorDirStat.apk` below and install it over the old one.
